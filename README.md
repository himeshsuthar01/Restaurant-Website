# Savoria Restaurant Website

A responsive multi-page restaurant website built with HTML, CSS, and Bootstrap 5.3.3.

## Pages
- `index.html` — Home
- `About.html` — About Savoria
- `Menu.html` — Menu
- `Gallery.html` — Gallery
- `Contact.html` — Contact and demo reservation form

## Folder structure
```text
restaurant-website/
├── index.html
├── About.html
├── Menu.html
├── Gallery.html
├── Contact.html
├── css/
│   └── style.css
└── image/
    └── Add your existing photo1.png to photo11.png files here
```

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**.

Note: Keep image filenames and capitalization exactly as used in the HTML. The reservation form is a front-end demo and does not submit bookings to a server.
